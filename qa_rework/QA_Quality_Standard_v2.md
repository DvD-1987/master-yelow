## 一、四个硬门槛（Gate 1-4，每题必须同时通过）

### Gate 1：Distractor Quality（干扰项质量）
- 错误选项必须**有知识依据、同层级、可单独成立**——删掉正确选项后，每个错误选项单独读起来都"像是一个可能对的答案"。
- 禁止：明显胡说项（明星/美食/足球/宠物/网红）、模板污染项（国家名、指数名、无意义短语）、廉价项（"结果更好/无关/不需要"）。
- 判定动作：先写正确项，再写三个"专业知识上只错一点"的错误项；每个错误项应命中一个真实业务误区或邻近概念。
- 反例：干扰项"仅供参观展示"（已修复，见 L6#638）；"硫让产品更亮"（已修复，见 L1#423）。
- 正例：L6#638 仲裁样 → 干扰项"用于向海关申报货值 / 保存满6个月后自行丢弃 / 用于下次装船参考"，均为检验实务中的真实误区。

### Gate 2：Topic Alignment（主题纯度）
- 题目必须证明"为什么属于当前关卡"，不得仅靠"同行业/沾边"进入。
- 各关主题锚点（冻结）：
  - L1 初到印尼（业务启动/市场/合规底线）
  - L2 煤炭基础（成煤/煤质指标/下游应用）
  - L3 资源收集（矿区考察/矿权合规/供应商尽调）
  - L4 贸易谈判（谈判策略/合同条款/结算）
  - L5 煤炭装载（装船作业/安全/计重）
  - L6 煤炭检验（取样/化验/标准/质量争议/仲裁）
- 判定动作：主题漂移直接 DROP，不重做。已执行案例：L1#855 过驳装船偏 L5、L2#175 港口装卸偏 L5、L2#336 船舶采样偏 L6、L2#504 仲裁检验偏 L6（REWORK 重走 Gate2 后转 DROP）。

### Gate 3：Single Best Answer（唯一最佳答案）
- 不得出现两个合理答案；正确项与干扰项不得语义近重复。
- 已执行案例：L2#10 收到基水分（Mar）原选项"水分/全硫/挥发分/煤中水分影响"层级混乱且与解释重复，重做为"结算重量与发热量折算"并配三个独立煤质概念干扰项。
- 判定动作：读题后先自答，再对答案；若自答与正解不一致，或有两个选项都可接受，判 REWORK。

### Gate 4：Game / Learning Value（游戏与学习价值）
- 优先考"判断与决策"，禁止"XX 是什么 / 意义是什么 / 正确态度是什么"的词典式背诵。
- 正例：收到基/空干基误用后果、Draft Survey 计算、GB vs ISO 冲突处理、滞期费触发条件、装船中明火/煤温异常撤离。
- 可接受保留的记忆类例外：必备贸易知识硬事实（如 Incoterms 2020 DAT→DPU 更名、ICI 分档定价方向），但每关此类占比不超过 15%。
- 场景化写法：给出业务情境（"你收到报价单/你准备谈判/矿方口头承诺"），问"此时你应怎么做/最应关注什么"。

## 二、两个辅助指标（非 Gate，用于排序与选题）

### 辅助指标 1：场景化程度（Scenario Score, 0-3）
- 3：完整业务情境 + 决策动作（"你与矿方谈判年度采购量，对方突然停回应，你更适合怎么做"）
- 2：业务场景但知识单一（"装船中哪种天气应停止作业"）
- 1：纯知识应用无情境（"ICI 指数热值每降一档价格如何变化"）
- 0：纯定义背诵（"XX 是什么"）
- 批量重构时：每关场景化程度 ≥2 的题应占 60% 以上；L7-L10 强制高于 L1-L6。

### 辅助指标 2：知识重复度（Dup Score）
- 同一知识点只允许 1 道题保留；"XX 的意义 / 正确态度 / 正确方式 / 是什么"系列视为同一知识簇。
- 同题干双题处理规则（已冻结，用于 16 对双题）：
  - 完全重复 → 合并/删除
  - 同题干但不同知识点 → 保留，明确区分条件（改题干/改设问）
  - 本质同题 → 留一重写一
- 新题生成前必须与已冻结 Golden Set 251 题做知识点查重。

## 三、结构硬约束（沿用 V1，必须保留）

1. 题干完整、以 ？结尾、≥12 字；选项恰 4 项且恰 1 correct。
2. 选项长度均衡（max ≤ 2.5*min+6）；同语义层级；禁止模板污染词。
3. explanation ≥20 字：先讲"为什么对"，再讲"为什么错"（至少覆盖主干扰项）。
4. 难度梯度：L2 不得混入 PGNAA、daf、SCR 等高阶术语；专业跨度大的内容后移。
5. 结构校验 + 质量校验通过后再合并阶段保存；每关题型比例抽检。
